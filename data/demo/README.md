# Demo data — replace with validated research data

Everything in this folder is **synthetic**. It was generated by `scripts/generate-demo-data.js`
from the team's *initial hypothesis* skill lists (`data/taxonomy/roles.json`) using a seeded random generator.

- `job_postings_demo.csv` — 146 fictional postings ("Demo Company 001" …), source `DEMO (synthetic)`, no URLs.
  Includes one duplicate row and one unclassifiable row on purpose, to exercise data-quality checks.
- `professional_responses_demo.json` — 48 fictional professional survey responses (3 per role). Free text is prefixed `[Demo]`.

Because the demo is generated *from* the hypothesis, any ranking computed from it simply reflects the hypothesis.
It must never be presented as a research finding. All demo rows are stored with `data_origin = 'demo'`
and can be removed from the admin dashboard (Data management → Remove demo data).

There is intentionally **no** demo data for the student validation survey: that section stays empty until
real student responses are collected.
